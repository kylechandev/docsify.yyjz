# 数据云同步

一句话总结：如果不希望自己备份数据，希望登录一羽记账的账号后，自动恢复记账数据，并且在多设备/多人使用时能方便的查看账单，那么 数据云同步 非常适合你。

## 介绍

数据云同步支持 Android、iOS、鸿蒙 全平台数据同步。**仅 <font color=orange>永久会员(云同步)</font> 可用。**

?> **永久会员(云同步) 的区别？**  
相比于永久会员(本地)以及订阅会员，唯一的区别就是额外增加了**数据自动云同步，无需再备份与恢复**。

<br/>

?> **数据云同步 与 备份恢复 的区别？**  
备份与恢复 是**全量的**备份与恢复覆盖所有数据，就像文件备份一样。而数据云同步是跟随一羽记账的账号，登录账号后自动同步数据，**在多设备使用时可以方便的来回同步显示数据**，无需再自己考虑数据备份存储的问题。

备份(本地/WebDAV云盘)为免费功能，无需开通会员。

<br/>

?> **数据云同步 使用说明**  
有/无网络场景都支持记录数据，网络恢复后 App 会自动完成同步。云同步在多设备使用时非常方便，在一台设备上对账单的添加/修改/删除操作，能直接在另一台设备上立即查看(通过下拉刷新/切换前后台)。

## 数据同步状态

云同步的数据保存在一羽记账的账号服务器中，数据永久保存，无需担心数据丢失问题。

同时`在一羽记账中删除的数据`在云服务器中有一定的缓存期，等待缓存期结束后才会真正的从服务器彻底抹除掉数据。如果有误操作删除数据，可以[联系我](doc/other/contact.md)帮助恢复误删除数据。

## 启用「数据云同步」后

> 数据将始终自动与云端保持同步，以防冲突，本地备份/云备份的恢复备份将被自动忽略<br><br>使用云同步后，也无需再关心备份，数据将实时自动与云端同步保存<br><br>但仍可以继续备份，以保留备份文件在身边作为保险
